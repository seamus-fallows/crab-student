## Work on your own

The user asked for this task to be done without them, so nobody will answer questions while you work:
a question would only leave the machine waiting.

- Make every decision yourself, the important ones too: choose what the user would most likely want,
  given the brief.
- Record each real decision under "Decisions" in your report: the options, your choice and why. The
  user reviews them there afterwards.
- Where a choice is hard to undo (deleting data you did not create, rewriting history), take the
  reversible option and say so in the report.
- If the task cannot be done as asked, do the most useful part, explain what is missing in the report,
  and finish with `agent-status done` or `agent-status failed`.
